> **۱۲.۳: لازم نیست.** صاحبِ کانال روی فیسبوک کار نمی‌کند؛ مقصدِ فیسبوک خاموش می‌ماند و اینستاگرام به این گام‌ها بند نیست. این راهنما فقط برای روزی است که خودِ او بخواهد.

# روشن کردنِ فیسبوک — راهنمای کوتاه (12.1)

> ساختِ کلید و هر کاری که رمز می‌خواهد **فقط کارِ صاحبِ کانال** است. کلید هرگز در شیت یا چت نوشته نمی‌شود.

1. business.facebook.com → **Business Settings** → **Users → System users** → `engine-bot`.
2. **Assign assets** → **Pages** → صفحهٔ Truth Trace → **Full control** (یا دستِ‌کم «Create content»).
3. همان‌جا **Generate new token** → اپِ Truth Trace → اجازه‌های فعلیِ اینستاگرام را نگه دارید و این سه را اضافه کنید:
   `pages_manage_posts` · `pages_read_engagement` · `pages_show_list`.
4. کلید را **فقط** از منوی موتور «۴) کلیدِ اینستاگرام (متا)» بچسبانید (خودِ صاحبِ کانال). موتور با آزمونِ بی‌انتشار می‌سنجدش.
5. در تختهٔ «مجموعه‌های آموزشی و پیشرفت» → «🎯 مقصدها» → ردیفِ **فیسبوک** را تیک بزنید.
6. سنجش: `_STATUS.facebook.line` باید «📘 فیسبوک: روشن» بگوید؛ اگر متا کلیدِ صفحه را ندهد، علتش به همین زبان در «آخرین وضعیت» و تلگرام می‌آید.

نکته: اگر اپ در حالتِ Development است، پست‌ها ممکن است فقط برای نقش‌دارانِ اپ دیده شوند — پس از نخستین ریلز، صفحه را از یک حسابِ بیرونی ببینید.
